# AulaSense

Repositorio principal para controlar el hardware, firmware y documentación de AulaSense.

## Estado actual

- Hardware: HW 0.1 DRAFT
- Firmware: FW 0.1.0-dev
- Etapa: planificación y prototipo inicial

## Organización

- `hardware/kicad`: esquema y PCB.
- `hardware/libraries`: símbolos y huellas propias.
- `hardware/manufacturing`: entregables para fabricación.
- `firmware`: código fuente del dispositivo.
- `docs`: arquitectura, planificación y compatibilidad.

## Versionado

El hardware utiliza versión y revisión física, por ejemplo `HW 1.0 Rev A`.

El firmware utiliza versiones `MAYOR.MENOR.CORRECCIÓN`, por ejemplo `FW 1.2.3`.
